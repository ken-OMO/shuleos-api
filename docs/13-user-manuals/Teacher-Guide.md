# Purpose

This guide explains how teachers use ShuleOS to manage teaching activities, student learning, assessments, attendance, communication, and academic reporting.

Teachers are responsible for maintaining accurate academic records while supporting student learning and engagement.

---

# Teacher Responsibilities

Teachers are responsible for:

- Managing assigned classes
- Recording attendance
- Managing assessments
- Recording grades
- Monitoring student progress
- Communicating with students and parents
- Maintaining accurate academic records

---

# Teacher Dashboard

The teacher dashboard provides quick access to:

- Today's classes
- Timetable
- Attendance
- Assignments
- Assessments
- Student summaries
- Notifications
- Reports

Dashboard content depends on assigned teaching responsibilities.

---

# My Classes

Teachers can:

- View assigned classes
- View class lists
- Access student profiles
- Review attendance
- Monitor academic progress

Teachers can only access classes assigned to them.

---

# Timetable

The timetable allows teachers to:

- View teaching schedule
- Check classroom assignments
- Review lesson times
- Identify upcoming sessions

---

# Attendance

Teachers should record attendance promptly for every scheduled class.

Attendance statuses may include:

- Present
- Absent
- Late
- Excused

Attendance records should be accurate and completed on the same day whenever possible.

---

# Lesson Planning

Teachers may use ShuleOS to:

- Plan lessons
- Record learning objectives
- Organize teaching resources
- Track curriculum coverage

Lesson plans should align with the school's academic calendar.

---

# Assignments

Teachers can:

- Create assignments
- Set due dates
- Attach learning materials
- Publish assignments
- Review submissions

Assignment instructions should be clear and complete.

---

# Assessments

Teachers manage:

- Continuous assessments
- Quizzes
- Practical work
- Projects
- Examinations

Assessment schedules should follow institutional policies.

---

# Grading

Teachers can:

- Record marks
- Review grades
- Update assessment results
- Submit final grades

Grades should be verified before publication.

---

# Student Progress

Teachers can monitor:

- Academic performance
- Attendance trends
- Assignment completion
- Assessment history
- Overall progress

Early identification of learning challenges supports student success.

---

# Student Profiles

Teachers may view:

- Student information
- Attendance history
- Assessment records
- Academic reports
- Parent contact information where permitted

Access is limited to authorized information.

---

# Communication

Teachers may communicate through:

- Announcements
- Class notices
- Assignment notifications
- Parent messages where permitted

Professional communication standards should always be maintained.

---

# Reports

Teachers can generate reports including:

- Class attendance
- Assessment summaries
- Grade reports
- Student performance
- Class statistics

Reports should be reviewed before sharing.

---

# Notifications

Teachers receive notifications for:

- New assignments
- Assessment deadlines
- School announcements
- Timetable updates
- Student activities

Notifications should be reviewed regularly.

---

# Academic Integrity

Teachers should:

- Maintain accurate records
- Grade fairly
- Protect assessment confidentiality
- Follow institutional academic policies

---

# Security

Teachers should:

- Protect login credentials
- Never share accounts
- Log out from shared devices
- Report suspicious activity

---

# Best Practices

Teachers should:

- Record attendance promptly.
- Publish grades carefully.
- Keep lesson information current.
- Review student progress regularly.
- Communicate professionally.
- Protect student privacy.

---

# Troubleshooting

Common issues include:

- Attendance submission problems
- Assignment upload errors
- Grade entry issues
- Report generation delays
- Login problems

Consult the Troubleshooting Guide or contact support if needed.

---

# Getting Help

If assistance is required:

1. Review this guide.
2. Consult the FAQ.
3. Contact your School Administrator.
4. Contact platform support if necessary.

# Final Standard

Teachers play a central role in the success of ShuleOS by maintaining accurate academic records, supporting student learning, and communicating effectively with the school community.

Consistent use of the platform helps create a reliable, transparent, and collaborative learning environment that supports the vision of the School in the Clouds.
