# Purpose

This User Manual provides an overview of the ShuleOS platform and serves as the primary guide for all users.

It introduces the platform, explains its major capabilities, and directs users to role-specific documentation for detailed instructions.

---

# About ShuleOS

ShuleOS is a cloud-based School Management System (SMS) designed to help educational institutions manage academic, financial, administrative, and communication processes from a single integrated platform.

The platform supports:

- School Administrators
- Teachers
- Students
- Parents
- Finance Officers
- Support Staff

---

# Vision

ShuleOS aims to become the complete digital operating system for schools by simplifying management, improving communication, and supporting better educational outcomes.

---

# Key Features

ShuleOS provides:

- Student Information Management
- Admissions
- Academic Management
- Attendance Tracking
- Timetable Management
- Assessments and Examinations
- Finance and Billing
- Reports and Analytics
- Parent Communication
- Notifications
- User Management
- Multi-school and Multi-tenant Support

---

# User Roles

Different users have different permissions.

Major user roles include:

- Super Administrator
- School Administrator
- Teacher
- Student
- Parent
- Finance Officer
- Registrar
- Librarian
- Support Staff

Each role only accesses features required for their responsibilities.

# Logging In

Users should:

- Use authorized credentials.
- Keep passwords confidential.
- Enable multi-factor authentication where available.
- Log out after completing their work on shared devices.
