# ShuleOS Architecture Decision Records

> School in Clouds

## Purpose

This directory contains the official Architecture Decision Records for ShuleOS.

Architecture Decision Records preserve the context, reasoning, alternatives, consequences, and governance of significant engineering decisions.

ADRs are permanent engineering records. Accepted ADRs are not deleted when decisions change. They are superseded by newer ADRs so that the architectural history of ShuleOS remains traceable.

## Authority

The ShuleOS Engineering Constitution is the highest engineering authority.

ADRs apply the Constitution to specific architectural decisions.

Where an ADR conflicts with the Engineering Constitution, the Constitution prevails.

## ADR Lifecycle

Each ADR uses one of the following statuses:

- Proposed
- Under Review
- Accepted
- Implemented
- Superseded
- Rejected
- Archived

## Naming Convention

ADR files use this format:

```text
ADR-NNNN-Decision-Title.md
```
